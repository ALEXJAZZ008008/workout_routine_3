\textbf{PROGRESSION \& RECOVERY}\par\vspace{0.6mm}
\begin{minipage}[t]{0.485\linewidth}\raggedright
\textbf{Reps:} One printed target applies to both sets. Increase by 1 rep per set only when both sets succeed; otherwise repeat.\par
\textbf{Weight:} Increase after both sets reach the maximum; restart at minimum. If too heavy, record actual reps and rebuild.\par
\textbf{Effort:} Main work about 1 RIR (last set 0--1 possible). Air bike: controlled hard effort, not an all-out sprint.
\end{minipage}\hfill\begin{minipage}[t]{0.485\linewidth}\raggedright
\textbf{Rest:} Alternate sets with your partner; allow extra recovery as needed. Rest between bike intervals as needed.\par
\textbf{Plateaus:} Technique, control and ROM gains count. If half or more movements stall or regress for 3 consecutive sessions, skip the next session, then resume.
\end{minipage}
